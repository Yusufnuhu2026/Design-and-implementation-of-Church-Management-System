# Design-and-implementation-of-Church-Management-System
Getting member Closer to God
ECWA Church Information Website

A responsive church website developed as a case study of the Evangelical Church Winning All (ECWA).

The website provides information about the church, its leadership, ministries, events, sermons, announcements and contact details. It also includes a prayer request form.

Technologies Used

HTML5

CSS3

JavaScript

LocalStorage

Features

Responsive homepage

About the Church

Church ministries and leadership

Upcoming events

Sermons and announcements

Prayer request form

Contact and WhatsApp integration

How to Run

Open the project folder in VS Code.

Open index.html.

Run with Live Server.

Live (https://churchinformation.netlify.app)
